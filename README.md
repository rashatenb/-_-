# Мои библиотеки для M5StickC Plus2

Привет! Это коллекция моих open-source библиотек для M5StickC Plus2 на MicroPython.

## 📚 Библиотеки

### NanoGL
Легковесная графическая библиотека с оптимизированным рендерингом:
- Полосный буфер (экономия RAM)
- Dirty tracking (ускорение отрисовки в 5-10 раз)
- LUT-кэширование шрифтов

##  Цель
